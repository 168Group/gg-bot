# Supplemental upstream license texts

These unmodified license texts supplement npm packages that omit a license file. Review them when updating the associated dependency; they are not relicensed by OMOBot.

- Drizzle ORM 0.45.3: https://github.com/drizzle-team/drizzle-orm/blob/main/LICENSE
- Sapphire async-queue 1.5.5 and snowflake 3.5.5: https://github.com/sapphiredev/utilities/blob/main/LICENSE.md
- abstract-logging 2.0.1: https://jsumners.mit-license.org/ (linked from the package README; article text retained)

Other dependency notices are read directly from their installed package license/notice files or README license sections. Run `pnpm licenses:generate` after reviewing dependency changes.
